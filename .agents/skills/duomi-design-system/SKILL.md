# DUOMI Design System

## 品牌
- 主色：DUOMI 原版橙色 Logo
- 辅色：暖白、深灰
- 风格：Apple / Tesla 式现代极简
- 无冗余图片、复杂阴影及花哨装饰

## 办公系统
- 正文通常采用 14–16px
- 保持清晰字体层级、行高和留白
- 按钮对比度明确
- 表格、卡片、导航统一设计
- 适合长时间办公

## 性能
- 优先低负载方案
- 减少图片与不必要动画
- 避免无意义的持续动效
- 微信小程序保持轻量

## 业务
- 保留原系统真实字段与业务逻辑
- 未经授权不修改数据库与业务接口
- 不虚构项目、费用、施工数据
- Web 与小程序使用统一视觉语言

## 优先级
- 用户明确需求优先
- DUOMI 规范优先于 TasteSkill 的通用建议
- TasteSkill 仅作为 UI 工程方法补充
